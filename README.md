# Trade Demo Outreach

Personalized demo pages for German construction subcontractor outreach. One Next.js app + Supabase serves N branded prospect pages at `/p/[slug]`.

## Quick start

```bash
npm install
npm run dev
```

Then visit:

- http://localhost:3000 — generic landing
- http://localhost:3000/p/mueller-trockenbau — sample personalized prospect page
